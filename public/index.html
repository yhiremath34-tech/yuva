Security Specifications

            

            
            

              

                

                  
                  Zero Client-Side Leaks
                

                The administrator password does not exist in any client-side JavaScript, HTML, or stylesheet. Inspecting page source reveals nothing.
              


              

                

                  
                  PBKDF2-HMAC-SHA256 Hashing
                

                Stored credentials use 300,000 hashing iterations combined with a cryptographically secure 128-bit random salt per account.
              


              

                

                  
                  Decoupled API Key Model
                

                Client websites submit feedback using scoped API keys (`fbk_live_...`), isolating public submissions from administrative controls.
